# Tech Stack – SentinelIQ (AI Developer 2 Project)

## 1. Backend Framework
- Flask (Python)
- Used to build REST API endpoints like /generate and /health

## 2. AI Model Integration
- Groq API
- Used for fast and efficient AI response generation

## 3. Programming Language
- Python
- Used for backend logic, API handling, and AI integration

## 4. Logging System
- Python logging module
- Stores logs in /logs/app.log for debugging and monitoring

## 5. Security Features
- Input validation
- Prompt injection protection
- Security headers
- Error handling system

## 6. Deployment Support
- Docker (containerization)
- Ensures consistent environment across systems

## 7. API Communication
- REST API architecture
- JSON request/response format
