# Day 16 - Talking Points Card

## Project
SentinelIQ AI Service

---

## What is this project?
AI backend using Flask + Groq API that generates responses from prompts.

---

## What is Groq?
High-speed AI inference API used to generate responses from LLM models.

---

## What is a prompt?
User input given to AI (question or instruction).

Example:
"Explain dark mode UI"

---

## System Flow
User → Flask API → Groq → AI Model → Response

---

## Security Points
- API keys stored in .env file
- No hardcoded secrets
- Secure API communication

---

## Final Summary
This project demonstrates real-time AI response generation using API integration.
